Foundry No. 9Editorial build
Objects / Philadelphia / 2026
Objects made to outlive us.
01 / RoleArt direction + design + front-end
02 / StackNext.js / React / GSAP
03 / FocusMotion + responsive choreography

Make the site feel like the object.

The design language is built around restraint, permanence, honest materials, and objects that age well. The interface needed weight, silence, scale, and enough motion to feel cinematic without turning into a demo reel.

01 / Composition

Editorial, not carded.

Large type, long image planes, asymmetry, negative space, and full-width transitions replace a conventional stack of reusable marketing cards.

02 / Motion

Movement with a job.

GSAP sequences control hero reveals, image scale, horizontal collection movement, and studio transitions. Reduced-motion preferences are respected instead of ignored.

03 / Mobile

A different composition.

The phone version drops desktop-only sticky choreography, changes typography and image ratios, simplifies motion, enlarges touch targets, and preserves the identity without forcing desktop behavior onto a small screen.

The craft has to hold up in every frame.

The live site includes the complete collection, object pages, studio story, custom pointer behavior, and responsive motion system.
